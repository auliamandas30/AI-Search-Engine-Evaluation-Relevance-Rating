### 🌐 Case Study: AI Search Engine Evaluation & Relevance Rating

**Brief Description:**
Acted as a quality evaluator for generative AI features on a major search engine. Responsible for analyzing, rating, and improving the relevance and accuracy of AI-driven search results based on user intent and comprehensive search quality guidelines.

**Tasks & Responsibilities:**
- **Search Intent Analysis:** Evaluated user search queries to determine true intent and assessed whether the AI-generated responses successfully addressed those needs.
- **Fact-Checking & Source Verification:** Conducted in-depth investigations into AI-generated claims, cross-referencing them with credible web sources to prevent misinformation and ensure grounding.
- **Relevance & Quality Rating:** Assigned ratings to AI search interface components based on metrics such as usefulness, information completeness, and content safety.
- **Qualitative Feedback:** Authored detailed, logical justifications (in both English and Indonesian) to explain the rationale behind each quality metric assessment.
